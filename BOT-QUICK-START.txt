⚡ TEZKOR BOSHLASH (5 MINUT)

STEP 1: Node.js O'rnatish
  Mac: brew install node
  Windows: https://nodejs.org/

STEP 2: Bot Token Olish
  1. Telegram'da @BotFather'ga yozing
  2. /newbot yuboring
  3. Token olab, saqlang

STEP 3: Setup
  mkdir 7075-bot && cd 7075-bot
  cp bot-package.json package.json
  npm install
  cp .env.example .env

STEP 4: Config
  .env'da BOT_TOKEN ni yangi token bilan almashtiring

STEP 5: Ishga Tushirish
  npm run dev
  ✅ Bot online!

🤖 BOT FOYDALANISH

YO'LOVCHI:
  /start → "👤 Yo'lovchi" tanlash
  Telefon + Ism kiriting
  "🔍 Safar qidirish" → Yo'nalish tanlang
  "✅ Band qilish" → Haydovchi tasdiqlashni kutish

HAYDOVCHI:
  /start → "🚗 Haydovchi" tanlash
  Moshina, raqam, telefon, ism kiriting
  "🚗 Elon qo'shish" → Yo'nalish, vaqt, narx
  Yo'lovchilar ko'radi va band qiladi
  Notification keladi → ✅ Tasdiqlash

MATCHING:
  Yo'lovchi band qilsa → Haydovchiga notification
  Haydovchi tasdiqlasa → Yo'lovchiga notification
  Ikkisi ham tasdiqlasa → Chat ochiladi
